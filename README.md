# One Line to Your Younger Self

A make.fun entry: the single line I would send back to my younger self.

`main.py` writes the line to `/output/entry.txt` (UTF-8, 1–200 characters).

Run it with `python3 main.py` — set `MAKEFUN_OUTPUT_DIR` to choose the output folder.
